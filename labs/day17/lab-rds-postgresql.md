### 4.3 Run analytical queries

```sql
-- Total revenue by payment type
SELECT
    payment_type,
    COUNT(*)            AS trip_count,
    SUM(total_amount)   AS total_revenue,
    AVG(fare_amount)    AS avg_fare,
    AVG(trip_distance)  AS avg_distance
FROM taxi_trips
GROUP BY payment_type
ORDER BY total_revenue DESC;

-- Busiest hours
SELECT
    EXTRACT(HOUR FROM pickup_datetime) AS pickup_hour,
    COUNT(*) AS trips
FROM taxi_trips
GROUP BY pickup_hour
ORDER BY trips DESC;

-- Trips longer than 5 miles
SELECT
    vendor_id,
    trip_distance,
    fare_amount,
    pickup_datetime::DATE AS trip_date
FROM taxi_trips
WHERE trip_distance > 5.0
ORDER BY trip_distance DESC;

-- Revenue per mile by vendor
SELECT
    vendor_id,
    ROUND(AVG(fare_amount / NULLIF(trip_distance, 0)), 2) AS revenue_per_mile
FROM taxi_trips
GROUP BY vendor_id;
```

## Part 5: Indexes and Query Performance

### 5.1 Create an index

```sql
-- Add an index on pickup_datetime for range queries (common in time-series data)
CREATE INDEX idx_trips_pickup_dt ON taxi_trips (pickup_datetime);

-- View existing indexes
SELECT
    indexname,
    indexdef
FROM pg_indexes
WHERE tablename = 'taxi_trips';
```

### 5.2 Use EXPLAIN to see query plan

```sql
-- Before index understanding - examine the query plan
EXPLAIN ANALYZE
SELECT *
FROM taxi_trips
WHERE pickup_datetime BETWEEN '2024-01-15' AND '2024-01-16';
```

Look for:
- **Index Scan** or **Seq Scan** in the plan output
- **Execution Time** in milliseconds
- **Rows** returned vs rows scanned

### 5.3 Create additional structures

```sql
-- Create a summary view
CREATE VIEW daily_summary AS
SELECT
    pickup_datetime::DATE   AS trip_date,
    COUNT(*)                AS trips,
    SUM(total_amount)       AS revenue,
    AVG(trip_distance)      AS avg_miles
FROM taxi_trips
GROUP BY trip_date
ORDER BY trip_date;

-- Query the view
SELECT * FROM daily_summary;

-- Create a second table for vendors
CREATE TABLE vendors (
    vendor_id   VARCHAR(10) PRIMARY KEY,
    vendor_name VARCHAR(100),
    city        VARCHAR(50)
);

INSERT INTO vendors VALUES
('CMT',  'Creative Mobile Technologies', 'New York'),
('VTS',  'VeriFone Transportation Systems', 'New York');

-- Join the tables
SELECT
    v.vendor_name,
    COUNT(t.vendor_id) AS trips,
    SUM(t.fare_amount) AS total_fare
FROM taxi_trips t
JOIN vendors v ON t.vendor_id = v.vendor_id
GROUP BY v.vendor_name
ORDER BY total_fare DESC;
```

## Part 7: Backup and Restore Concepts

### 7.1 View automated backup in the Console

1. RDS Console → **Databases** → `$PREFIX-$BATCH-postgres`
2. Click **Maintenance and backups** tab
3. Scroll to **Automated backups** — note the latest snapshot timestamp

### 7.2 Create a manual snapshot via CLI

```bash
export AWS_PROFILE=aws-de-lab

# Create a manual snapshot (takes 3–10 minutes)
aws rds create-db-snapshot \
  --db-instance-identifier $PREFIX-$BATCH-postgres \
  --db-snapshot-identifier $PREFIX-$BATCH-manual-snap-day17

# Monitor snapshot status
aws rds describe-db-snapshots \
  --db-snapshot-identifier $PREFIX-$BATCH-manual-snap-day17 \
  --query 'DBSnapshots[0].{Status:Status,Progress:PercentProgress,AllocatedStorage:AllocatedStorage}' \
  --output table
```

> Note: Manual snapshots are kept until you delete them. Automated backups are retained for the configured retention period.

### 7.3 List your snapshots

```bash
aws rds describe-db-snapshots \
  --db-instance-identifier $PREFIX-$BATCH-postgres \
  --query 'DBSnapshots[*].{Identifier:DBSnapshotIdentifier,Status:Status,Type:SnapshotType,Created:SnapshotCreateTime}' \
  --output table
```

## Part 8: Monitoring with CloudWatch

### 8.1 View metrics in the Console

1. RDS Console → `$PREFIX-$BATCH-postgres` → **Monitoring** tab
2. After your queries from Part 4, look for:
   - **DatabaseConnections** — should have spiked when you connected
   - **WriteIOPS / ReadIOPS** — visible after INSERTs and SELECTs
   - **FreeStorageSpace** — should show minimal change (tiny dataset)

### 8.2 Query metrics via CLI

```bash
# DatabaseConnections metric for the last hour
aws cloudwatch get-metric-statistics \
  --namespace AWS/RDS \
  --metric-name DatabaseConnections \
  --dimensions Name=DBInstanceIdentifier,Value=$PREFIX-$BATCH-postgres \
  --start-time $(date -u -d '1 hour ago' +%Y-%m-%dT%H:%M:%SZ) \
  --end-time $(date -u +%Y-%m-%dT%H:%M:%SZ) \
  --period 60 \
  --statistics Maximum \
  --output table
```
